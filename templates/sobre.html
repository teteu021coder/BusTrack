Sobre o BusTrack

Um sistema web para facilitar o acesso a informações sobre o transporte público.

O projeto

O BusTrack é um projeto de Trabalho de Conclusão de Curso (TCC) do curso técnico de TI. Ele reúne em uma única aplicação web a consulta de linhas, trajetos, pontos de parada e horários de ônibus.

Problema

Informações de transporte público costumam estar espalhadas em tabelas, placas e sites pouco amigáveis, o que dificulta o planejamento da viagem.

Objetivo

Oferecer uma interface moderna, responsiva e intuitiva para consultar o transporte público, com mapa interativo, busca e horários organizados por tipo de dia.

Sobre os dados

  • Linhas, paradas e horários são fictícios e foram criados apenas para demonstrar o sistema.
  • Os ônibus no mapa são simulados: a posição é calculada a partir dos horários cadastrados, sem nenhuma fonte de localização real.
  • A estrutura do banco permite importar dados oficiais (por exemplo, arquivos GTFS) no lugar dos dados de demonstração.
  • Localização em tempo real de ônibus reais depende de uma API do operador. A SPTrans (cidade de São Paulo) oferece a API "Olho Vivo", que exige cadastro e token, e atende apenas essa cidade.
